## Required submission material

- Names and email addresses for every teammate. WorldSpec is a solo project.
- A public GitHub repository.
- A public demo video that is three minutes or shorter.
- Answers to every HackHub project question.
- A final manual check that every submitted link is publicly accessible.

The HackHub interface may mention a four-minute minimum. The organizer's Discord message is authoritative: the video must be three minutes or shorter or the project may not be considered.
